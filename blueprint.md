# Legacy Planning Application Blueprint

## Overview

This document outlines the development plan for a Legacy Planning application. The application is designed to help Relationship Managers (RMs) guide their clients through the legacy planning process in a structured and user-friendly way. It will be a single-page web application.

## Current Implemented Features

*   **Client Discovery Form:** A web component (`<legacy-planning-form>`) that captures the client's basic profile, health information, and a financial snapshot.
*   **Corporate Styling:** The application is styled with a corporate color scheme of blue, green, and white.
*   **Conditional Legacy Checklist:** An interactive checklist for single or divorced individuals.

## Current Request: Comprehensive Legacy Planning Form

This section outlines the plan to create a professional and comprehensive legacy planning form tailored for Singapore's banking and insurance relationship managers.

*   **Objective:** To create a feature-rich, user-friendly, and professional form that captures all necessary information for legacy planning in the Singaporean context.

### Plan

1.  **Restructure the Form:** The form will be organized into the following sections:
    *   Personal Information
    *   Assets (with dynamic entry)
    *   Debts & Liabilities (with dynamic entry)
    *   Legal & Estate Planning
    *   Financial Partners
    *   Organ Donation Wishes (with HOTA information)

2.  **Implement Dynamic Fields:** Users will be able to add and remove multiple assets and liabilities.

3.  **Professional Design:**
    *   A professional gradient background will be applied.
    *   The form layout will be improved for better readability and user experience.
    *   The form will be mobile-responsive.

4.  **Form Validation:** Required fields will be validated to ensure data integrity.

5.  **Submission and Summary:**
    *   Upon submission, the form data will be collected.
    *   A summary of the entered information will be displayed to the user for review.
